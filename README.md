# Vinheria Agnello
### Projeto Checkpoint 1 de Web Development 

## Sistema basico para cadastro de vinhos artesanais da Vinheria Agnello, feito com JavaScript usando prompt(), alert() e console.log().

## Como funciona
### Quando abre a pagina o sistema pede o nome, tipo, safra e quantidade do vinho. Depois mostra tudo no console (F12 > Console).
